## How to reproduce

```bash
cd tf-api
npm run hdfc:scenarios                      # the whole pack
npm run hdfc:scenarios -- --sheet=break-in  # one sheet
npm run hdfc:scenarios -- --rows=28,29      # single conditions
npm run hdfc:scenarios -- --rps=0.25        # slower, if HDFC 429s
npm run hdfc:scenarios -- --regen           # rebuild this file, no live calls
```

Raw per-row request and response bodies are written to `scripts/_hdfc-uat-scenario-results.json` (gitignored by `scripts/_*`).
